# Rugby Technologies Website Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the Create Next App starter with a polished, static one-page Rugby Technologies business website that explains four services and converts visitors through a pre-addressed email.

**Architecture:** Keep the existing Next.js App Router page as a Server Component and render all content statically. Use native anchors and `details` elements for interaction, Tailwind utilities for layout, and a small global CSS layer for brand tokens and decorative motion; add no runtime services or dependencies.

**Tech Stack:** Next.js 16.3.4, React 19.2.8, TypeScript, Tailwind CSS 4, Biome 2.4.2

**Spec:** `docs/superpowers/specs/2026-09-02-rugby-technologies-website-design.md`

## Global Constraints

- Read the spec before changing source files.
- Read the relevant local Next.js guides under `node_modules/next/dist/docs/` before implementation because this repository uses Next.js 16.3.4.
- Do not add packages, Client Components, forms, APIs, analytics, images, a CMS, or new routes.
- Do not mention Sean Aguilar, a founder, sports, a portfolio, testimonials, corporate clients, or enterprise clients in rendered content.
- Keep `app/page.tsx` as a Server Component and use native browser behavior for navigation, FAQ disclosure, and email.
- Keep the approved recipient, subject, and body text exact.
- Do not run lint, build, browser checks, commit, push, or deploy without the user's explicit authorization at that stage.
- Preserve unrelated worktree changes and stage only the approved website files if commit authorization is later granted.

## File Map

- Modify `app/layout.tsx`: global metadata, fonts, language, and document shell.
- Modify `app/page.tsx`: all static content, page landmarks, navigation, CTAs, and FAQ disclosure.
- Modify `app/globals.css`: Tailwind import, brand tokens, base accessibility styles, decorative grid, and reduced-motion behavior.
- Read `docs/superpowers/specs/2026-09-02-rugby-technologies-website-design.md`: approved product, content, visual, and acceptance requirements.

No test file is added. The page contains no non-trivial application logic, and the repository has no test runner; source-contract checks plus the approved lint/build/manual gate cover this static change without introducing test infrastructure.
